# Coiffeur — Site Vitrine

Site vitrine statique pour un salon de coiffure, conçu pour présenter les services et les tarifs aux clients.

---

## Présentation

Ce projet est un site vitrine développé en HTML, CSS et JavaScript. Il a pour objectif de donner une présence en ligne professionnelle à un salon de coiffure, avec une mise en page claire et responsive.

---

## Fonctionnalités

- **Accueil / Hero** — Section d'accroche principale avec mise en avant du salon
- **Services & Tarifs** — Présentation structurée des prestations et de leurs tarifs

---

## Technologies

| Technologie | Rôle |
|-------------|------|
| HTML5 | Structure et sémantique des pages |
| CSS3 | Mise en forme, responsive design |
| JavaScript | Interactions et comportements dynamiques |

## Installation

### Prérequis

- [Node.js](https://nodejs.org/) (version LTS recommandée)
- npm (inclus avec Node.js)

### Étapes

1. Cloner le dépôt :
   ```bash
   git clone https://github.com/nicolas234567/Coiffeur_Site_Vitrine.git
   cd Coiffeur_Site_Vitrine
   ```

2. Installer les dépendances :
   ```bash
   npm install
   ```

3. Lancer le projet en local :
   ```bash
   npm start
   ```

   Le site sera accessible à l'adresse `http://localhost:3000` ou sur le port indiqué dans le terminal.

---

## Responsive Design

Le site est conçu pour s'adapter à l'ensemble des formats d'écran courants : ordinateurs de bureau, tablettes et appareils mobiles.

---

## Personnalisation

Pour adapter ce projet à un autre salon :

1. **Contenu textuel** — Modifier directement `index.html`
2. **Styles et couleurs** — Éditer les variables et règles dans `css/style.css`
3. **Images** — Remplacer les fichiers présents dans `assets/images/`
4. **Tarifs** — Mettre à jour la section Services dans le fichier HTML
